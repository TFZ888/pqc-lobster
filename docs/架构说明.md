# pqclaw 架构说明

## 一句话

pqclaw 是挂在 OpenClaw（龙虾）外面的"抗量子安全门卫"：
- **进门**：你的 API 密钥要先进抗量子"保险箱"（加密），启动时再取出来用；
- **防篡改**：配置文件带抗量子签名，谁改过立刻发现。

## 模块关系

```
┌─────────────────────────────────────────────┐
│  OpenClaw（龙虾核心）                        │
│   DeepSeek 对话 · 飞书机器人 · Gateway 网关  │
└───────────────────┬─────────────────────────┘
                    │ 使用加密后的密钥 / 校验签名
┌───────────────────▼─────────────────────────┐
│  pqclaw 抗量子安全层                         │
│                                              │
│   pqcrypto.py  ──  ML-KEM-768（密钥封装）    │
│                 └─ ML-DSA-65（数字签名）     │
│                                              │
│   keystore.py  ──  API Key 密文保险箱        │
│                 └─ 配置签名 / 验签           │
│                                              │
│   cli.py       ──  init / seal / open /      │
│                    sign / verify / demo      │
└──────────────────────────────────────────────┘
```

## 算法说明（NIST 标准）

| 算法 | 用途 | 对应旧标准 |
|---|---|---|
| ML-KEM-768 | 密钥封装（加密机密信息） | Kyber768 |
| ML-DSA-65 | 数字签名（防篡改） | Dilithium3 |

这两种算法均被 NIST 标准化（FIPS 203 / FIPS 204），量子计算机无法破解。

## 安全目录（~/.pqclaw/）

| 文件 | 内容 | 权限 |
|---|---|---|
| kem_public.key | 抗量子封装公钥 | 644 |
| kem_secret.key | 抗量子封装私钥 | 600 |
| dsa_public.key | 签名公钥 | 644 |
| dsa_secret.key | 签名私钥 | 600 |
| api_key.sealed | 加密后的 API Key（密文） | 600 |

> 私钥文件丢失后密文无法解密，请妥善备份。
